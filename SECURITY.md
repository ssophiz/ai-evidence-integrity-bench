# Security reporting

This repository is a synthetic research benchmark. Its provenance gate checks
claim-ID membership and requires separate semantic review; it does not certify
the safety of a model or evidence pipeline. The demo is intended for local use
with synthetic data. See [ETHICS.md](ETHICS.md) and [THREAT_MODEL.md](THREAT_MODEL.md).

GitHub private vulnerability reporting is not enabled for this repository.
For non-sensitive security concerns, open an
[issue](https://github.com/ssophiz/ai-evidence-integrity-bench/issues) with the
affected revision, expected behavior, and a minimal synthetic example.

Do not include credentials, private evidence, personal data, or sensitive
vulnerability details in a public issue. If a report needs confidential
handling, first open an issue requesting a private reporting channel without
including those details. No confidential contact or response-time commitment
is currently published here.
